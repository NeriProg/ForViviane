# Só para você

Site estático em português para apresentar uma carta de amor. Abra o arquivo
index.html no navegador para ver a prévia. O botão de música toca uma melodia
instrumental sintetizada pelo próprio site.

## Colocar a carta

Edite assets/carta.js. Preencha o título, os parágrafos e a assinatura, e altere
previa para false. Para inserir uma quebra de linha dentro de um parágrafo,
use \n na posição desejada.

## Publicação

A raiz contém os arquivos estáticos e pode ser servida pelo GitHub Pages. A
publicação e a configuração do repositório remoto ficam para depois da aprovação.
